# وثيقة بيان الأصول (Assets) — تطبيق وِفرة

> مستقلة عن باقي الوثائق. قائمة رسمية بكل ملف بصري/خط يحتاجه فريق UI قبل البدء، بمساراته المتوقعة داخل مجلد `assets/`.

---

## 1. الشعار

```
assets/logo/
 ├─ logo.svg              (المصدر الأساسي، متجه)
 ├─ logo_light.png        (خلفية فاتحة، للاستخدام خارج التطبيق)
 ├─ logo_dark.png          (خلفية داكنة)
 ├─ app_icon_android.png   (512x512، لأيقونة التطبيق على المتجر)
 └─ app_icon_ios.png       (1024x1024)
```
التصميم المرجعي: دائرة بلون `primary`، أيقونة محفظة بخط واحد بلون فاتح، نقطة صغيرة بلون `secondary` (راجع وثيقة التصميم القسم 1).

## 2. أيقونات الأصناف/المنتجات

مجموعة أيقونات مصغّرة (line icons) موحّدة الأسلوب البصري مع الشعار (خط واحد، بلا تعبئة)، بصيغة SVG، بحجم تصميم أساسي 24x24. المجموعة الأولية المقترحة تغطي أشيع فئات المصاريف المنزلية:
```
assets/icons/categories/
 ├─ food.svg          (طعام/بقالة)
 ├─ transport.svg      (مواصلات)
 ├─ health.svg          (صحة)
 ├─ home.svg            (منزل/إيجار)
 ├─ electricity.svg     (كهرباء — نفس أيقونة البرق المستخدمة بالمقياس الدائري)
 ├─ shopping.svg        (تسوق عام)
 ├─ entertainment.svg   (ترفيه)
 ├─ other.svg           (أخرى — تُستخدم كافتراضي عند عدم اختيار المستخدم أيقونة)
```
**ملاحظة مهمة:** المستخدم يقدر يضيف صنفًا/منتجًا جديدًا بأي وقت (راجع وثيقة المنطق)، لذلك يجب أن تكون هذه المجموعة **قابلة للاختيار من قائمة عند الإضافة**، وليست أيقونات مبرمجة يدويًا لكل صنف — الشاشة تعرض هذه المجموعة كخيارات، والمستخدم يختار الأقرب لصنفه.

## 3. أيقونات النظام والحالات

هذه ليست جزءًا من مجموعة الأصناف، بل أيقونات وظيفية تستخدمها المكوّنات المشتركة مباشرة:
```
ti-bolt              → مقياس الطاقة (قسم الكهرباء)
ti-alert-triangle    → AppErrorBanner
ti-check             → علامة نجاح العملية
ti-chevron-down/up   → توسّع بطاقة الحركة
ti-chevron-right/left→ تنقل الروزنامة
ti-plus              → زر الإضافة الرئيسي
ti-x                 → إغلاق البانر
ti-settings          → شاشة الإعدادات
```
(هذه من مكتبة أيقونات جاهزة يحددها فريق التطوير عند الربط الفعلي بـ Flutter — لا حاجة لتصميمها يدويًا، فقط توثيق الاسم المستخدم لكل غرض هنا لضمان توحيد الاستخدام).

## 4. الخطوط

```
assets/fonts/
 ├─ Cairo-Regular.ttf    (وزن 400 — النصوص العادية)
 └─ Cairo-Medium.ttf     (وزن 500 — العناوين والأزرار فقط)
```
لا حاجة لأي وزن Bold (700) — راجع وثيقة التصميم القسم 3: وزنان فقط بكل التطبيق. (البديل Tajawal بنفس الوزنين إن فُضِّل بصريًا لاحقًا).

## 5. أنيميشن الشعار (شاشة التحميل)

لا حاجة لملف Lottie أو فيديو خارجي — نقاط النبض الثلاث في شاشة التحميل (حركة كتالوج التصميم) تُبنى بكود CSS/Flutter مباشرة (Keyframe animation)، وليست أصلًا بصريًا منفصلًا.

---

## ملخص ما يحتاج فريق UI تجهيزه فعليًا قبل البدء

1. تصدير الشعار بصيغة SVG نظيفة (من المعاينة الحية المرسلة سابقًا أو نسخة معاد رسمها بنفس المواصفات).
2. اختيار/تصميم 8 أيقونات أصناف بنفس أسلوب الخط الواحد.
3. تحميل ملفي خط Cairo (Regular + Medium) وربطهما بمشروع Flutter.
