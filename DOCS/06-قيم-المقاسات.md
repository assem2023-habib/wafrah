# وثيقة قيم المقاسات — تطبيق وِفرة

> مستقلة عن باقي الوثائق. أرقام نهائية وحاسمة لكل قيمة هندسية في `core/constants/app_dimens.dart` — لا اجتهاد فردي من أي عضو بالفريق.

---

## 1. الحشوات (Padding)

| Token | القيمة | الاستخدام |
|---|---|---|
| `paddingXs` | 4px | مسافة داخل عناصر صغيرة جدًا (شارة/Badge) |
| `paddingSm` | 8px | مسافة بين عناصر متقاربة داخل بطاقة |
| `paddingMd` | 16px | الحشوة الداخلية القياسية لأي بطاقة أو شاشة |
| `paddingLg` | 24px | مسافة حول العناصر الرئيسية (زر الحفظ، عنوان الشاشة) |
| `paddingXl` | 32px | فواصل بين أقسام كبيرة داخل نفس الشاشة |

## 2. المسافات بين العناصر (Gap)

| Token | القيمة | الاستخدام |
|---|---|---|
| `gapXs` | 4px | بين أيقونة ونصها الملاصق |
| `gapSm` | 8px | بين تسمية الحقل والحقل نفسه |
| `gapMd` | 12px | بين بطاقات متتالية في قائمة |
| `gapLg` | 20px | بين مجموعات حقول مختلفة بنموذج الإضافة |

## 3. نصف قطر الزوايا (Radius)

| Token | القيمة | الاستخدام |
|---|---|---|
| `radiusSm` | 8px | الحقول النصية والرقمية، الأزرار الثانوية |
| `radiusMd` | 12px | البطاقات الفرعية داخل شاشة (بطاقة يوم بالروزنامة مثلًا) |
| `radiusLg` | 16-20px | البطاقات الرئيسية (AppCard) |
| `radiusFull` | 50% | العناصر الدائرية (الشعار، دائرة الأفاتار/الأيقونة، مقياس الطاقة) |

## 4. الأزرار والحقول

| Token | القيمة | ملاحظة |
|---|---|---|
| `buttonHeight` | 48px | الحد الأدنى الثابت لكل الأزرار |
| `fieldHeight` | 52px | أعلى قليلًا من الزر لأن النص الرقمي بحجم أكبر |
| `iconButtonSize` | 40px | أزرار الأيقونة فقط (تنقل الروزنامة، إغلاق البانر) |
| `touchTargetMin` | 44px | الحد الأدنى المطلق لأي عنصر قابل للمس بكل الشاشة |

## 5. الأيقونات

| Token | القيمة | الاستخدام |
|---|---|---|
| `iconSm` | 16px | أيقونات مرافقة لنص صغير |
| `iconMd` | 20-22px | أيقونات الحقول وشريط التنقل |
| `iconLg` | 28px | أيقونات الصنف/المنتج داخل البطاقات |
| `iconXl` | 40px+ | أيقونة الشعار داخل الدائرة، أيقونة الحالة الفارغة |

## 6. الحدود (Border)

| Token | القيمة |
|---|---|
| `borderThin` | 0.5px (فواصل خفيفة) |
| `borderDefault` | 1px (حدود الحقول والبطاقات) |
| `borderAccent` | 1.5-2px (حلقة "اليوم" بالروزنامة، تمييز مقصود) |

## 7. الطباعة (أرقام نهائية)

| Token | القيمة |
|---|---|
| `fontCaption` | 12px |
| `fontLabel` | 14px |
| `fontBody` | 16px (الحد الأدنى المطلق بكل التطبيق) |
| `fontHeading` | 20-22px |
| `fontStatNumber` | 28-32px |
| `lineHeight` | 1.5 (ثابت على كل الأحجام) |

## 8. مدد الحركة (مرجع سريع، التفصيل الكامل في وثيقة التصميم القسم 7)

| Token | القيمة |
|---|---|
| `durFast` | 120-200ms (ضغط زر، انتقال شاشة) |
| `durBase` | 300-350ms (توسّع بطاقة، علامة النجاح) |
| `durSlow` | 700-900ms (عدّاد أرقام، نمو رسم بياني، مقياس الطاقة) |
