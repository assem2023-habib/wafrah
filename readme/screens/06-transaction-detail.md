# الشاشة 6: تفاصيل الحركة (Transaction Detail)

> **المسار:** `/transaction-detail` · **الملفات:** `lib/modules/transaction_detail/*` · تستقبل معرف الحركة عبر `Get.arguments`

## الغرض

عرض كل بيانات حركة، وتعديلها أو حذفها.

## عناصر الواجهة

| العنصر | التفاصيل |
|---|---|
| البطاقة الرئيسية | دائرة 64 بأيقونة الاتجاه على تدرج لوني، المبلغ بإشارة ± بحجم 30 (اتجاه LTR للرقم)، وشارة «دخل/مصروف» بلون النوع (أخضر/برتقالي) |
| بطاقة التفاصيل | صفوف: الصنف، المنتج (إن وجد)، التاريخ بصيغة كاملة «الثلاثاء 12 أغسطس 2026»، الملاحظة إن وُجدت |
| زر التعديل | ثانوي بأيقونة قلم — ينقل لشاشة الإضافة في **وضع التعديل** |
| زر الحذف | رئيسي بلون الخطر؛ عند لمسه **يتحول موضعاً** إلى قسم تأكيد مضمّن |

## تأكيد الحذف المضمّن (بدل نافذة منبثقة)

كما في المرجع: يختفي زر الحذف ويظهر مكانه سؤال «هل أنت متأكد من حذف هذه المعاملة؟» وزران متجاوران: «تأكيد الحذف» (أحمر) و«إلغاء». لا نوافذ AlertDialog منفصلة.

## الحالات الأربع (DOCS 07 §5)

- **عادية:** العرض أعلاه.
- **فارغة:** لا تنطبق (لا تُفتح إلا لحركة موجودة) — مع ذلك تعالج حالة عدم وجود المعاملة برسالة «المعاملة غير موجود... غير موجودة».
- **تحميل:** لحظي من السجل.
- **خطأ:** فشل حفظ التعديل يظهر بنفس أسلوب شاشة الإضافة.

## المنطق المرتبط

- بعد أي تعديل وحفظ تعود للتفاصيل فتُحدّث بياناتها تلقائياً (`RouteAware.didPopNext`).
- الحذف ينفّذ مباشرة عند التأكيد ثم يعود للسجل، والرئيسية والسجل يتحدثان تلقائياً بدورهم.

## التنقل

- رجوع بالهيدر · تعديل ← إضافة مصروف/دخل بوضع التعديل · تأكيد الحذف ← عودة للسجل.
