# الشاشة 9: الإحصائيات (Statistics)

> **المسار:** `/statistics` · **الملفات:** `lib/modules/statistics/statistics_view.dart`, `statistics_controller.dart`, `statistics_binding.dart`

## الغرض

إعطاء المستخدم صورة فورية عن توزيع مصاريفه ومقارنة دخله ومصاريفه عبر الزمن، بلا جداول معقدة.

## عناصر الواجهة

| العنصر | التفاصيل |
|---|---|
| شريط الفترات | حبوب قابلة للتمرير: «هذا الشهر / 3 أشهر / 6 أشهر / سنة» — الحبة المختارة خلفية `primary` ونص `onPrimary`، الباقي `muted`/`textSecondary` |
| بطاقتا الملخص | إجمالي الدخل (خلفية `primary/10` ونص `primary`) وإجمالي المصاريف (`secondary/10` ونص `secondary`)، كل قيمة من `NumberFormatter.formatSyp` |
| بطاقة التوزيع الدائري | عنوان «توزيع المصاريف» + دونات `PieChart` (مسافة مركزية 55، حلقة 30) + أسطورة 5 أصناف كبرى (نقطة لونية + الاسم + القيمة) |
| بطاقة الأعمدة الشهرية | عنوان «الدخل والمصاريف شهرياً» + `BarChart` بعمودين لكل شهر (دخل `primary` ومصروف `secondary` بزوايا 4) + صفوف شهرية تفصيلية تحت الرسم (نقطة + تسمية + قيمة) |

## الحالات الأربع (DOCS 07 §8)

- **عادية:** الملخص + الدونات (إن وجدت مصاريف) + الأعمدة الشهرية.
- **فارغة:** لا بيانات في النافذة المختارة → `AppEmptyState` «لا توجد بيانات / لا توجد معاملات في هذه الفترة».
- **تحميل:** شيمر ببطاقتي ملخص + بطاقتي رسم (260 و280).
- **خطأ:** لا ينطبق (شاشة عرض فقط).

## الحركات

- نمو الدونات عند الفتح عبر `TweenAnimationBuilder` (حركة #7، `durSlow` ≈ 700ms) مع `PieChart` بـ `duration` تكيفية.
- نمو الأعمدة عبر `BarChart` بـ `duration` تكيفية.
- كل المدد تمر عبر `Motion.dur` فتُعطل فوراً عند تفعيل «تقليل الحركة».

## المنطق المرتبط (`StatisticsController`)

- النافذة الزمنية: `periodMonths` (افتراضي 1) → `windowStart = DateTime(now.year, now.month - (months-1))` — «هذا الشهر» = بداية الشهر الحالي فقط.
- `inPeriod`: كل `Transaction` حيث `!date.isBefore(windowStart)` مرتبة تنازلياً.
- `totalIncome`/`totalExpense`: مجموع الفترة.
- `expenseByCategory`: تجميع مصاريف الفترة بحسب `categoryId` وترتيب تنازلي بالقيمة.
- `monthlyBuckets`: تجميع شهري `{income, expense}` مفتاحه أول الشهر، تسمية الشهر بـ `DateFormat('MMM','ar')`.
- الألوان من `context.chartColors` (`AppPalette` يرجع `lightChart`/`darkChart` حسب الثيم).
