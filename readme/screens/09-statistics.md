# الشاشة 9: الإحصائيات (Statistics)

> **المسار:** `/statistics` · **الحالة:** 🚧 قيد التطوير — تُعرض حالياً شاشة «سيتوفر قريباً» (`ComingSoonView`) والمسار آمن بلا تعطل

## المواصفة المعتمدة للبناء (DOCS 01 §5.8 + DOCS 02 §7)

عند التنفيذ سيُلتزم بما يلي:

### التبويب العلوي
- أزرار كبيرة واضحة: **اليوم / الأسبوع / الشهر** — بدل TabBar الافتراضي الرفيع غير المناسب لكبار السن.

### الرسمان البيانيان
1. **رسم دائري:** توزيع المصاريف حسب الصنف، **ينمو تدريجياً عند الفتح** (حركة #7، 600–800ms).
2. **رسم عمودي:** مقارنة الدخل/المصاريف لنفس الفترة.

### الفلاتر
- فلاتر اختيارية بالصنف والمنتج **تُطبَّق على الرسمين معاً** في آن واحد.

### المنطق الحسابي (DOCS 02 §7)
- الحساب بتوقيت الجهاز المحلي مباشرة.
- يومي = مقارنة صرف اليوم بالمتوسط اليومي التاريخي؛ والأسبوعي/الشهري بنفس المبدأ.
- عرض الأرقام بصيغة العملة الموحدة (اختصار مليون/مليار) من `NumberFormatter`.

### الحالات (DOCS 07 §8)
- **فارغة:** لا بيانات كافية للفترة → «لا توجد بيانات لهذه الفترة» بدل رسم فارغ مربك.
- **تحميل:** شيمر بشكل دائرة/أعمدة رمادية قبل نمو الرسم الحقيقي.
- **خطأ:** لا ينطبق (شاشة عرض فقط).

### المكتبة المستخدمة
`fl_chart` موجودة في المشروع مسبقاً وستلوّن الرسوم من Tokens الثيم (`chartColors` المتكيّفة مع الوضع الليلي في `AppPalette`).
