# الشاشة 7: إدارة الأصناف (Categories)

> **المسار:** `/categories` · **الملفات:** `lib/modules/categories/*`

## الغرض

إدارة أصناف المصاريف/الدخل التي تُبنى عليها شاشات الإضافة والإحصائيات. **أهم حالة فارغة في التطبيق** — بدونها لا تعمل شاشة إضافة مصروف.

## عناصر الواجهة

| العنصر | التفاصيل |
|---|---|
| زر «+» | دائرة `primary` بارتفاع لمس 40 في الهيدر — يفتح نموذج الإضافة |
| صف الصنف | بطاقة: دائرة أيقونة + اسم الصنف + وصف نوعه (مصروف/دخل/كلاهما) + زرا تعديل وحذف |
| نموذج الصنف | بطاقة تحوي: حقل الاسم (خطأ inline «الاسم مطلوب») · قائمة النوع · شبكة 12 أيقونة Tabler للاختيار (المختصر بإطار أخضر) · حفظ/إلغاء |

## قاعدة منع الحذف (DOCS 02 §3)

عند محاولة حذف صنف:
- له **أي حركة** مرتبطة → يُمنع الحذف نهائياً.
- له **منتج واحد على الأقل** → يُمنع أيضاً حتى لو لم تكن له حركات مباشرة (حماية مرجعية المنتج).

في الحالتين يظهر **بانر خطأ ثابت** أعلى القائمة: «يوجد بيانات سابقة مرتبطة بهذا العنصر، لا يمكن حذفه» — بلا خيار حذف قسري، ولا يختفي إلا بإغلاقه يدوياً.

## الحالات الأربع (DOCS 07 §6)

- **عادية:** قائمة الأصناف.
- **فارغة:** «لا توجد أصناف / ابدأ بإضافة صنف جديد» **مع زر «إضافة صنف» بارز** داخل الحالة الفارغة نفسها.
- **تحميل:** لحظي من Hive.
- **خطأ:** بانر منع الحذف المذكور أعلاه.

## المنطق المرتبط

- التعديل يعيد استخدام النموذج مع تعبئة الاسم والنوع والأيقونة (`startEdit`).
- الحذف يفحص مستودعي الحركات والمنتجات قبل التنفيذ.

## التنقل

- يُفتح من الإعدادات ← قسم البيانات، ومن الحالة الفارغة لشاشة إضافة المصروف.
