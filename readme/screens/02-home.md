# الشاشة 2: الرئيسية / لوحة القيادة (Home)

> **المسار:** `/home` · **الملفات:** `lib/modules/home/home_view.dart`, `home_controller.dart`, `home_binding.dart`

## الغرض

لوحة القيادة: نظرة فورية على الوضع المالي، وأسرع طريق لتسجيل حركة جديدة.

## عناصر الواجهة

| العنصر | التفاصيل |
|---|---|
| الترويسة | «أهلاً بك في» + «وِفرة» يمين، زرا أيقونة يسار: قمر (تبديل الوضع الليلي — محفوظ) وترس (الإعدادات) |
| بطاقة الرصيد | خلفية `primary` كاملة، «الرصيد الكلي» + الرقم بحجم 32 بعدّاد متحرك 800ms + «ل.س» + تذييل «جميع المعاملات» |
| بطاقتا الملخص | متجاورتان: إجمالي الدخل (أخضر `primary` بحد جانبي) وإجمالي المصاريف (برتقالي `secondary`)، كل رقم بعدّاد 900ms وسطر وحدة أسفله |
| آخر المعاملات | عنوان + زر «عرض الكل»؛ بطاقة واحدة تحوي آخر 5 حركات مفصولة بخطوط رفيعة، كل صف بأيقونة اتجاه ملونة + اسم الصنف/النوع + تاريخ أو ملاحظة + المبلغ بإشارة ± |
| زر الإضافة العائم SpeedDial | يطفو أسفل-يسار فوق المحتوى؛ عند اللمس يدور «+» بـ45° ويكشف زرين: «دخل» أخضر ثم «مصروف» برتقالي، مع ظل وانكماش لمس |

## الحالات الأربع (DOCS 07 §1)

- **عادية:** البطاقات الثلاث + القائمة كما فوق.
- **فارغة (أول تشغيل):** لا معاملات إطلاقاً → حالة فارغة ترحيبية «مرحباً بك في وِفرة!» وزر «أضف أول معاملة» ينقل لشاشة إضافة مصروف — لا أرقام ولا «متوسطات» مضللة.
- **تحميل:** شيمر على شكل البطاقات الفعلية (بطاقة كبيرة + بطاقتان نصفيتان + صفي قائمة).
- **خطأ:** لا يوجد إجراء يفشل عادة؛ بانر خطأ عام إن حدث.

## الحركات

عدّادات count-up للرصيد والملخصين · ظهور متتالٍ staggered (80ms بين عنصر) لصفوف آخر المعاملات · دوران وتغير لون زر الإضافة · انكماش عند الضغط. **كلها تتعطل بمفتاح «تقليل الحركة».**

## المنطق المرتبط

- الرصيد = إجمالي الدخل − إجمالي المصاريف.
- تنسيق العملة: كامل بفواصل حتى مليون، ثم «1.2 مليون ل.س» ثم «مليار» (`NumberFormatter.formatSyp`).
- التحديث التلقائي عند العودة من شاشات الإضافة عبر `RouteAware.didPopNext`.
