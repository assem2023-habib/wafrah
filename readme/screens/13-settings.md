# الشاشة 13: الإعدادات (Settings)

> **المسار:** `/settings` · **الملفات:** `lib/modules/settings/*`

## الغرض

مركز التخصيص: المظهر، الوصول لإدارة البيانات، تعرفة الكهرباء التي تعتمد عليها كل حسابات القسم.

## الأقسام الأربعة

### 1. المظهر
- **الوضع الليلي:** مفتاح Switch بحجم لمس كبير — يبدّل الثيم فوراً عبر `Get.changeThemeMode` ويحفظه في صندوق Hive مستقل (`ui`) فيُستعاد عند الإقلاع قبل بناء التطبيق.
- **تقليل الحركة:** يفعّل `Motion.reduced` فوراً؛ **كل حركات التطبيق** (عدادات، staggered، نبضات، شيمر، نقاط التحميل...) تتعطل دفعة واحدة والرسوم تصبح ثابتة — حماية لمن يفضل واجهة ساكنة تماماً (DOCS 01 §7 قاعدة الكتالوج).

### 2. البيانات
صفان قابلان للضغط بأيقونات وسهم: «إدارة الأصناف» و«إدارة المنتجات» — البوابة الوحيدة المنظمة لهاتين الشاشتين.

### 3. تعرفة الكهرباء (DOCS 01 §5.12 + DOCS 07 §12)
- **مدة الدورة (بالأشهر):** `AppNumberField`.
- **الشرائح:** بطاقة لكل شريحة فيها «حد الشريحة (ك.و)» و«سعر الك.و (ل.س)» + زر حذف للبطاقة (لا يُحذف آخر شريحة) وزر «إضافة شريحة».
- **حفظ التعرفة** بزر رئيسي معطل أثناء التنفيذ.
- **التحقق (DOCS 02 §4):** مدة > 0 · كل حد/سعر > 0 · **حدود الشرائح تصاعدية بلا تداخل أو تكرار** وإلا بانر خطأ ثابت. عند النجاح شارة خضراء «تم الحفظ بنجاح!» قابلة للإغلاق.
- القيم الافتراضية من `app_defaults.dart` عند أول فتح (شريحة 300 ك.و × 600).

### 4. أخرى
بطاقة «عن التطبيق»: الشعار + الاسم + «الإصدار 1.0.0» + التذييل.

## الحالات الأربع (DOCS 07 §12)

- **عادية:** كل الحقول بقيمها المحفوظة أو الافتراضية.
- **فارغة/تحميل:** لا تنطبق فعلياً — الإعدادات دائماً لها قيمة وتقرأ من Hive فوراً.
- **خطأ:** بانر عند إدخال شرائح متداخلة أو غير منطقية.

## ملاحظة معمارية

وضع المظهر وتقليل الحركة مخزنان في صندوق `ui` الخاص بالتفضيلات (منفصل عن بيانات الأعمال)، بينما التعرفة تُخزن ضمن `ElectricitySettings` في صندوق الإعدادات الرئيسي — فصل مصادر الحقيقة بحسب طبيعتها.
