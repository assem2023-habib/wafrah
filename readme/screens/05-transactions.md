# الشاشة 5: سجل الحركات (Transactions)

> **المسار:** `/transactions` · **الملفات:** `lib/modules/transactions/*`

## الغرض

سجل كامل لكل حركات التطبيق مع بحث وفلاتر قابلة للدمج، مقسمة زمنياً.

## عناصر الواجهة

| العنصر | التفاصيل |
|---|---|
| البحث | حقل «بحث...» بأيقونة عدسة — يطابق اسم الصنف أو المنتج أو نص الملاحظة |
| شريط الفلاتر | صف أنواع (الكل/دخل/مصروف) كأزرار كبسولية + حقلا اختيار الصنف والمنتج + صف فترات (اليوم/الأسبوع/الشهر) + زر «مسح الفلاتر» بلون الخطر عند تفعيل أي فلتر |
| القائمة | مجموعات بحسب اليوم بعنوان تاريخ كامل عربي؛ كل مجموعة بطاقة واحدة تحوي صفوف الحركات بنمط الرئيسية نفسه |

**الفلاتر الأربعة قابلة للدمج في آن واحد** (نوع + صنف + منتج + فترة) — وثيقة المنطق §6.

## الحالات الأربع (DOCS 07 §4)

- **عادية:** المجموعات الزمنية.
- **فارغة — حالتان مختلفتان إلزامياً:** (أ) لا حركات بالتطبيق إطلاقاً → «لا توجد معاملات بعد». (ب) توجد حركات لكن لا نتيجة → «لا توجد نتائج / جرّب تعديل الفلاتر» **مع زر مسح الفلاتر**.
- **تحميل:** شيمر بصفوف بطاقات.
- **خطأ:** بانر عام إن فشل حذف (نادر).

## المنطق المرتبط

- فرز تنازلي بالتاريخ ثم تجميع باليوم (`groupedByDate`).
- فلتر الفترة: اليوم = منذ منتصف الليل؛ الأسبوع = آخر 7 أيام؛ الشهر = الشهر الحالي.
- فلتر المنتج يُظهر فقط الحركات التي لها ذلك المنتج تحديداً (الدخل ومصاريف «بدون منتج» تبقى ظاهرة عند فلترة الصنف/الفترة فقط).
- التحديث التلقائي عند العودة عبر `RouteAware`.
- الحذف يتم من شاشة التفاصيل وليس من هنا.

## التنقل

- شريط سفلي: الرئيسية(0) · الإحصائيات · الكهرباء · ضغط صف ← تفاصيل الحركة (تمرير `id`).
