# الشاشة 8: إدارة المنتجات (Products)

> **المسار:** `/products` · **الملفات:** `lib/modules/products/*`

## الغرض

إدارة المنتجات المرتبطة بالأصناف، لتمكين تفاصيل أدق في المصاريف (مثل «خبز» ضمن صنف «طعام وشراب») وفلتر المنتج في السجل والإحصائيات.

## عناصر الواجهة

| العنصر | التفاصيل |
|---|---|
| زر «+» | في الهيدر كشاشة الأصناف |
| المجموعات | المنتجات مجمعة تحت ترويسة صنفها (دائرة أيقونة + اسم الصنف) — يعرض «اسم صنفه» بوضوح كما تشترط الوثيقة 5.7 |
| صف المنتج | الاسم + زرا تعديل وحذف |
| نموذج المنتج | حقل الاسم (خطأ inline) + قائمة الصنف **إجبارية** بخطأ inline «اختر الصنف» + حفظ/إلغاء |

## قاعدة منع الحذف

منتج له أي حركة مرتبطة → منع كامل مع البانر الثابت «يوجد بيانات سابقة مرتبطة...». نفس فلسفة الأصناف دون استثناء أو حذف قسري.

## الحالات الأربع (DOCS 07 §7)

- **عادية:** مجموعات مصنفة.
- **فارغة:** «لا توجد منتجات / ابدأ بإضافة منتج جديد» + زر «إضافة منتج».
- **تحميل:** لحظي.
- **خطأ:** بانر منع الحذف؛ وخطأ الصنف inline داخل النموذج عند الحفظ بدونه.

## المنطق المرتبط

- لا يمكن إنشاء منتج بدون صنف موجود فعلياً (`categoryOptions` تعرض مصروف/كلاهما فقط).
- عند اختيار صنف مختلف أثناء التعديل يُحدّث `categoryId` ويُعاد تجميع القائمة تلقائياً.
- الحذف يفحص مستودع الحركات أولاً.

## التنقل

- يُفتح من الإعدادات ← قسم البيانات. (لا يُفتح من شاشة الإضافة مباشرة — المنتج يُختار هناك من قائمة جاهزة).
